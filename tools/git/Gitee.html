Gitee ​

国内的 Git 代码托管平台，对标 GitHub，由 OSCHINA（开源中国）开发运营，官网：gitee.com

一句话区分： Git = 本地版本控制软件（装在电脑上） Gitee / GitHub = 云端网站，用来存放、同步、协作管理代码仓库

✅ 核心功能 ​

  1. 代码版本托管：保存代码历史，随时回退版本；支持公开开源仓库、私有仓库。
  2. 团队协同：多人一起开发、代码评审、分支管理、提交记录查看。
  3. 配套工具：在线文档、任务看板、代码扫描、CI/CD 自动部署、云端 IDE 等 DevOps 能力。
  4. 私有化部署：企业可以部署在自己内网，适合政企对代码安全、国产化有要求的场景Gitee。

📌 特点 ​

  • ✅ 国内服务器，访问速度快，中文界面，GitHub 国内访问不稳定时最常用替代平台
  • ✅ 个人基础功能免费（私有仓库有免费额度），企业高级版收费
  • ✅ 大量国内开源项目托管在这里，也是学生、开发者常用的代码备份平台

🧩 常见用途 ​

  • 个人：代码备份、练手项目、作品集
  • 学生：课程作业、毕业设计代码托管
  • 团队 / 企业：内部项目协作、开源项目发布

注册 ​

  1. 打开 gitee.com

  2. 点击注册

  3. 上传头像后一路下一步直到进入到工作台

  1. 鼠标移动到头像上，点击账号设置

  1. 绑定第三方账号，任选一个即可

  2. 设置邮箱

  1. 创建项目

  1. 添加协作开发者，需要共同开发者提供Gitee协作账号

  1. 个人仓库地址

创建 git 仓库:

shell

git init # 初始化仓库
git add . # 将代码从工作区提价到暂存区
git commit -m "备注信息" # 将代码从暂存区提交到本地仓库
git remote add origin https://gitee.com/用户名/仓库.git  #第一次提交执行，关联仓库
git push -u origin master # 第一次从本地仓库向远端仓库推送

授权验证 ​

使用 HTTPS 协议时，命令行会出现如下账号密码验证步骤。基于安全考虑，Gitee 建议 配置并使用私人令牌 替代登录密码进行克隆、推送等操作

Username for 'https://gitee.com': 用户名

Password for 'https://用户名@gitee.com': 私人令牌或者密码（命令行输入密码时不显示）
